Helios Web is a web-based library to visualize dynamic networks in real-time. Currently under development it aims to provide a simple API and optimized implementation to be integrated in other systems and render and layout large networks.

View in full screen - Powered by Helios-Web
See Helios-Web in action for visualizing Twitter data in the Osome Network tool.

Check it out in:
https://github.com/filipinascimento/helios-web/
